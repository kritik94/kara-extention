# Караоке-очередь: первая итерация

**Версия:** 1.0
**Дата:** 2026-08-20

## Суть

Общая очередь YouTube-видео. Гости кидают ссылки с телефона, экран играет их
подряд. Ничего лишнего.

## Роли

- **Экран** — компьютер у телевизора с установленным Chrome-расширением.
- **Гость** — любой, кто открыл сайт комнаты с телефона.

Отдельной роли хоста нет. Хост — это человек, который подготовил экран; в самом
продукте у него нет особых прав.

## Требования

### Экран (расширение)

| ID | Требование |
|---|---|
| E-1 | Играет видео из очереди по порядку, сверху вниз |
| E-2 | По окончании видео сразу начинает следующее, без действий человека |
| E-3 | Сыгранное видео удаляется из очереди |
| E-4 | Получает изменения очереди, не перезагружая страницу |
| E-5 | Исполняет команду «пропустить»: обрывает текущее видео и переходит к следующему |
| E-6 | При пустой очереди ждёт; появилось видео — начинает играть |
| E-7 | Не даёт YouTube подставлять рекомендованные видео вместо очереди |

### Сайт (гость)

| ID | Требование |
|---|---|
| G-1 | Открывается по ссылке, без регистрации и установки |
| G-2 | Поле для вставки ссылки на YouTube-видео и кнопка «Добавить» |
| G-3 | Показывает текущую очередь: что играет сейчас и что дальше, по порядку |
| G-4 | Очередь обновляется сама, без перезагрузки страницы |
| G-5 | У каждого видео в очереди — кнопка удаления |
| G-6 | Кнопка «Пропустить» для текущего видео |
| G-7 | Показывает название видео, а не голую ссылку |
| G-8 | Понятная ошибка, если ссылка не распознана |

## Вне первой итерации

Поиск по YouTube, имена гостей, «мои песни», ротация по кругу, права
модерации, пауза, перемещение в очереди, история, дубль-детект, комнаты
(комната одна).

## Следствия, которые стоит принять осознанно

- **Удалять и пропускать может кто угодно что угодно.** Без имён гостей нет
  понятия «свой трек», а значит и никаких ограничений. Для компании друзей это
  нормально и экономит всю логику идентификации.
- **Ссылка вместо поиска.** Гость ищет песню в самом YouTube и копирует ссылку.
  Лишний шаг, зато нет квот API и целого экрана поиска.
- **Очередь — общая и одна.** Пока комнат нет, сервис рассчитан на один вечер в
  одном месте.

## Вопросы к решению до старта

1. Что делает экран, если очередь опустела прямо во время воспроизведения —
   остаётся на последнем кадре или показывает заглушку?
2. Принимаем ли ссылки с таймкодом (`&t=`), Shorts и `youtu.be`, или только
   канонический `watch?v=`?
3. Как гость получает ссылку на сайт — QR на экране или хост диктует адрес?
